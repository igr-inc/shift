シフト希望アプリ プライバシーポリシー

このページは、株式会社IGRが運営する店舗（カードショップあるぱか、いえろーきゃっと静岡店）のスタッフ向け「シフト希望アプリ」についての説明です。

1. 扱う情報

  • スタッフの名前と、各日の勤務希望（○／×／時間）、確定した勤務時間。
  • 店舗の営業日・定休日・臨時休業の予定。

2. 使いみち

  • 店舗のシフト表を作るため。入力した内容は、その店舗のGoogleアカウントが持つスプレッドシートに保存されます。
  • 臨時休業の予定を、店舗のGoogleカレンダーとGoogleビジネスプロフィール（Googleマップの店舗情報）の特別営業時間へ反映するため。

3. 第三者への提供

法令で求められる場合を除き、入力された情報を第三者に提供しません。広告や外部サービスへの送信も行いません。

4. Google のユーザーデータの扱い

このアプリが Google API を通じて取得・利用する情報は、上記の使いみち（スプレッドシートの読み書き、カレンダーとビジネスプロフィールの営業時間の更新、お知らせメールの送信）に限ります。Google API サービスのユーザーデータに関するポリシー（限定利用の要件を含む）に従います。
